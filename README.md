## Real Estate Valuation
# Overview

This project explores the factors that influence residential property values and uses machine learning to predict housing prices from real-world housing data.

The analysis examines how characteristics such as **house age, distance to public transportation, and the number of nearby stores** relate to property value. Using Python, Pandas, and scikit-learn, I will clean and explore the data, identify important relationships, and build regression models to predict property prices.

The goal is not only to develop an accurate prediction model, but also to understand which characteristics of a property are most strongly associated with its value.
